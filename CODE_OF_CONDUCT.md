# Code of conduct

This is a small open source project about helping people find work. Be the kind of person you would want reading your CV.

- Be kind and specific. Disagree with the idea, not the person.
- No harassment, discrimination or personal attacks, in issues, pull requests or anywhere the project is represented.
- Do not post anyone's private information, including a real CV, in an issue or pull request. Use a made up one.
- Assume good faith, and ask before assuming otherwise.

Maintainers may edit, hide or remove comments and contributions that break these rules, and may block repeat offenders.

To report a problem, write to praveenkpandu2@gmail.com. Reports are handled privately.
